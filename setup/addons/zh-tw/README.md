## 這個選配包加了什麼

繁中學術寫作有三個英文工具鏈照顧不到的層面，co-author / paper-review 在繁中模式要多跑：

1. **台灣慣用語檢查（陸用語 + 台/臺）**
   - 抓大陸用語（如「反饋 → 回饋」「軟件 → 軟體」「視頻 → 影片」「數據 →（視語境）資料/數據」），
     以及「台/臺」全篇一致。
   - 需要一份**誤判白名單**（有些詞在語境下是對的），避免機械式替換。
   - lite：Claude 依常見對照表逐項判斷並附引句；full：本機批次腳本掃全篇。

2. **官方術語譯名一致性**
   - 專有名詞、技術術語的中譯是否對齊**官方/權威譯名**（台灣有國家教育研究院樂詞網等權威來源），
     全篇同一概念用同一譯名。
   - 格式多為「中文（English）」夾注；掃全篇這種對照、標出不一致或非官方譯法。
   - lite：Claude 查權威譯名逐詞核對；full：本機比對官方譯名庫。

3. **中文 AI 句法指紋（去 AI 味，中文校準）**
   - 英文的 AI-tic 偵測搬到中文要重新校準：以漢字為分母算破折號／分號密度、三連並列密度、
     句長變異，並抓中文趨同詞（如「構成／正是／值得注意的是／不僅…更／進一步／彰顯／凸顯／
     賦予／誠然／某種程度上／換言之／旨在／致力於」）。
   - 🔴 保留「做概念工作」的修辭（對偶、論點收尾、嵌入問句），只動純插入語；同一稿**改前／改後
     比較最準**（中文缺乾淨基線時用啟發式門檻）。
   - 🔴 另一層人眼才看得到的「像 AI 潤過」的味道（三連當副歌、格言式段末、自我評價式收尾判語），
     統計指紋抓不到，交付前要另派一輪乾淨視角挑句。

## 作者的聲音（VOICE_PROFILE）在繁中特別重要

繁中是作者親寫、有把握「像他」的語言 → 一定對齊 `VOICE_PROFILE`。
🔴 常見 AI 壞習慣：擅自加「此即本作的賭注／恰恰是…價值所在／真正的…在於」這類**自我吹捧收尾判語**
——擴寫只陳述事實與論證，**判語留給作者**。
